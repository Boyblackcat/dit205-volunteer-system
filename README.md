# ระบบหาชั่วโมงทุน (RSU Scholarship Volunteer System)

โครงงานวิชา **DIT204 Information System Project Management / DIT205**  
วิทยาลัยนวัตกรรมดิจิทัลเทคโนโลยี มหาวิทยาลัยรังสิต  
จัดทำโดย **นายพจน์กฤษฎิ์ วรรณภาส (รหัสนักศึกษา 6801457)**

---

## ความสามารถหลักของระบบ

- **การแบ่งสิทธิ์ตามบทบาท (RBAC 5 บทบาท):** นักศึกษาทุน, ผู้จัดกิจกรรม, เจ้าหน้าที่ดูแลทุน, ผู้อนุมัติ และผู้ดูแลระบบ (Admin)
- **การจัดการประเภททุนการศึกษา:** รองรับการถือทุนหลักควบคู่กับทุน กยศ. คำนวณเป้าหมายชั่วโมงสะสมอัตโนมัติ พร้อมระบบยื่นคำขอแก้ไขทุนพร้อมแนบหลักฐาน
- **การจัดการและสมัครกิจกรรมจิตอาสา:** ตรวจสอบสิทธิ์ทุน, โควตาที่นั่ง และวัน-เวลาปิดรับสมัครอัตโนมัติ
- **เช็คชื่อหน้างานด้วย QR Code:** เปิดกล้องจริงสแกน QR Code (หรืออัปโหลดภาพ QR) เพื่อยืนยันการเข้าร่วมและป้องกันการเช็คชื่อซ้ำ
- **แนบหลักฐานและรับรองชั่วโมง 2 ระดับ:** บีบอัดรูปภาพอัตโนมัติก่อนอัปโหลด ผ่านการตรวจจากเจ้าหน้าที่ (`Officer`) และอนุมัติขั้นสุดท้ายจากผู้อนุมัติ (`Approver`)
- **แดชบอร์ดสถิติและกราฟ:** กราฟแท่งเปรียบเทียบรายเดือนและรายปี, จัดการปีการศึกษา, ส่งออกรายงาน CSV, บันทึกประวัติระบบ (`Audit Logs`) และซิงก์ข้อมูลถาวรกับ **TiDB Cloud**
- **รองรับโหมดมืด–สว่าง (Dark / Light Mode)** และการใช้งานบนมือถือ

---

## เทคโนโลยีที่ใช้

- **Frontend / Backend:** Next.js 14 (App Router), React 18, TypeScript, Tailwind CSS
- **Database & Storage:** TiDB Cloud (MySQL-compatible, TLS 1.2)
- **QR Code:** `qrcode` & `jsqr`

---

## การติดตั้งและรันระบบ

1. คัดลอกไฟล์ `.env.example` เป็น `.env.local` และตั้งค่าการเชื่อมต่อ TiDB Cloud และ `JWT_SECRET`
2. ติดตั้งแพ็กเกจและรันเซิร์ฟเวอร์:

```bash
npm install
npm run dev
```

เปิดใช้งานที่ `http://localhost:3000`
